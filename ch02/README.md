# 第2章　ルートユーザーとIAMユーザーをMFAで保護する

本の第2章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch02/…」は、このフォルダのファイルを指します。このフォルダには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- ルートユーザーと作業用の IAM ユーザーに MFA を設定できる
- MFA が無い認証情報の操作を拒否するポリシーを、IAM ユーザーに付けられる
- パスワードポリシーで、弱いパスワードを防げる

この章では、検証環境（`terraform apply` で作るリソース）を使いません。IAM を設定するだけなので、料金はかかりません。

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。本では、第1章で作る作業用フォルダ `aws-security-book` のファイルを書き換えながら進みます。このフォルダは書き換えた後の状態なので、自分のファイルとの比較に使います。AWS の料金は読者の負担で、攻撃の手順は自分が管理する AWS アカウントのリソースにだけ実行します（[リポジトリのトップ](../README.md)の「最初に読んでください」）。途中の章から始めるときは、トップの「途中の章から始めるとき」を見てください。

1. 作業用フォルダ `aws-security-book` に `policies` フォルダを作り、このフォルダの `policies/require-mfa.json` をコピーします。エディターで作るときは、名前の後ろに `.txt` が付いていないことを確かめます。

2. IAM の設定は、本の第2章の手順で行います。試しに作った IAM ユーザーは、章の終わりの案内のとおり削除します。

## うまくいったかの確かめ方

- `simulate-principal-policy` の結果が `explicitDeny` になる（本の第2章）

動作しないときは、本の第2章の「うまくいかないとき」を見てください。
