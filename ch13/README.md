# 第13章　Security Hubのセキュリティ標準でアカウント全体を評価する

本の第13章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch13/…」は、このフォルダのファイルを指します。このフォルダには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- Security Hub と Security Hub CSPM の FSBP 標準で、アカウント全体を点検できる
- 不合格の項目を振り分け、Terraform で直して合格を確かめられる

第12章の後に検証環境を削除したときは、第12章のコードで作り直してから進めます。Security Hub は `terraform destroy` で無効になります。30日間の無料期間の後は課金されるので、使い終わったら検証環境を削除します。

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。本では、第1章で作る作業用フォルダ `aws-security-book` のファイルを書き換えながら進みます。このフォルダは書き換えた後の状態なので、自分のファイルとの比較に使います。AWS の料金は読者の負担で、攻撃の手順は自分が管理する AWS アカウントのリソースにだけ実行します（[リポジトリのトップ](../README.md)の「最初に読んでください」）。途中の章から始めるときは、トップの「途中の章から始めるとき」を見てください。

1. 本の手順で、作業用フォルダのファイルを書き換えて `terraform apply` を実行します。書き換えた結果は、このフォルダのファイルと同じになります。

2. Security Hub の有効化は、本の第2節の `posture.tf` で行います。

3. 第14章に続けて進むときは、検証環境をこのまま使います。時間を空けるときは、次のコマンドで検証環境を削除します。`terraform destroy` では `yes` と入力します。Windows と Mac で同じコマンドです。

   ```text
   terraform destroy
   ```

## うまくいったかの確かめ方

動作しないときは、本の第13章の「うまくいかないとき」を見てください。
