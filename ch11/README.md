# 第11章　CloudTrail・VPCフローログ・WAFのログをAthenaで分析する

本の第11章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch11/…」は、このフォルダのファイルを指します。このフォルダには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- WAF のログと VPC フローログを S3 に集められる
- Athena で3種類のログのテーブルを作り、攻撃の跡を SQL で探せる

第10章の終わりに検証環境を削除したので、この章でも変更を先に書いてから構築します。約1時間使うと、0.2 USD ほどかかります（2026年11月時点）。

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。本では、第1章で作る作業用フォルダ `aws-security-book` のファイルを書き換えながら進みます。このフォルダは書き換えた後の状態なので、自分のファイルとの比較に使います。AWS の料金は読者の負担で、攻撃の手順は自分が管理する AWS アカウントのリソースにだけ実行します（[リポジトリのトップ](../README.md)の「最初に読んでください」）。途中の章から始めるときは、トップの「途中の章から始めるとき」を見てください。

1. 本の手順で作業用フォルダのファイルを書き換え、`terraform apply` を実行して `yes` と入力します。20分ほどかかります。

   ```text
   terraform apply
   ```

2. 作業を終えるときは、Terraform の管理の外にある Athena のテーブルを先に削除します。本の第6節の3つの SQL（`DROP TABLE`）を実行してから、`terraform destroy` を実行します。第12章に続けて進むときは、検証環境をそのまま使えます。

## うまくいったかの確かめ方

- `terraform apply` の前の確認で `Plan: 67 to add, 0 to change, 0 to destroy.` と表示される

動作しないときは、本の第11章の「うまくいかないとき」を見てください。
