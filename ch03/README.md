# 第3章　アクセスキーを廃止し、一時的な認証情報に切り替える

本の第3章を終えた時点のファイルです。本のコードの枠の上の「サンプルコード　ch03/…」は、このフォルダのファイルを指します。このフォルダには、それまでの章で使ったファイルもすべて入っています。

この章でできるようになること:

- 漏れたアクセスキーを無効にし、何に使われたかを調べられる
- 長期のアクセスキーをやめ、一時的な認証情報に切り替えられる

この章では、検証環境（`terraform apply` で作るリソース）を使いません。試しに使う IAM ユーザーと小さな S3 バケットだけを作り、章の終わりに削除します。料金は、S3 のごくわずかな保存料だけです。

## この章での使い方

コマンドは、Windows は PowerShell、Mac はターミナルで実行します。本では、第1章で作る作業用フォルダ `aws-security-book` のファイルを書き換えながら進みます。このフォルダは書き換えた後の状態なので、自分のファイルとの比較に使います。AWS の料金は読者の負担で、攻撃の手順は自分が管理する AWS アカウントのリソースにだけ実行します（[リポジトリのトップ](../README.md)の「最初に読んでください」）。途中の章から始めるときは、トップの「途中の章から始めるとき」を見てください。

1. 作業用フォルダ `aws-security-book` に `data` フォルダを作り、このフォルダの `data/customers.csv`（架空の顧客名簿）をコピーします。

2. 攻撃の試しと IAM の設定は、本の第3章の手順で行います。試しに作った IAM ユーザーと S3 バケットは、章の終わりの案内のとおり削除します。

## うまくいったかの確かめ方

- `list-access-keys` で何も表示されない（使っていないアクセスキーが残っていない）

動作しないときは、本の第3章の「うまくいかないとき」を見てください。
